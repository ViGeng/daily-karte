# Daily Karte for Raycast

This extension is an incomplete scaffold, and development remains paused. The shared `daily-karte@0.1.0` npm package is now published. The commands, native interactions, and live account synchronization have not been implemented or validated.

The extension will import its activity model and shared types from `daily-karte`. It will not maintain copies of those modules. Development can resume with `npm install` in this directory to create its independent lockfile and install the released package.

The current scaffold contains the extension manifest and an initial Google OAuth implementation. It is not ready to install or submit to the Raycast Store. The repository's `docs/npm-release.md` records the completed npm publication.
